A single original roast line about wireless earbuds: sold on the promise of
freedom, until one earbud takes that promise literally and walks out.

Run `python3 main.py` — it gates the line (UTF-8, 1–200 characters, not
whitespace-only) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`, then reads
it back and verifies it byte-for-byte.
